Quick Java Swing demo — adds a `UserName` label and a textbox named `txtUserName`.

Build & run (PowerShell):

```powershell
cd c:\Users\kenji\BT2-NHOM7
javac -d out src\Main.java
java -cp out Main
```

Notes:
- Ensure you have a JDK installed and `javac` on PATH.
- The UI uses Swing; the text field variable is `txtUserName` in `src/Main.java`.
